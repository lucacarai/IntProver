Original prover

The decision procedure is the original, unchanged fCube 11.1 Prolog program by Mauro Ferrari, Camillo Fiorentini, and Guido Fiorino. Its original source notices and README are preserved in the source download.

Original fCube README and copyright notice

Adaptation

Adaptation date: 5 October 2026. The browser interface, infix parser, mathematical preview, worker adapter, and static deployment packaging were added. These additions are distributed under GPL version 3 or later. The fCube decision procedure has not been modified.

Browser runtime

This application includes SWI-Prolog through the official swipl-wasm package, version 8.1.4, whose contributors are Raivo Laanemets, Jesse Wright, and Jan Wielemaker. Its runtime is distributed under the Simplified BSD license, with its own license notices preserved.
